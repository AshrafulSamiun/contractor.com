# DeskDrop Chat FAQ

## 1) What is DeskDrop?
DeskDrop is a parcel management platform for buildings and front desk teams. It logs, tracks, and delivers parcels with audit-ready status history.

## 2) Key features
- Parcel intake, storage location, and status updates
- Recipient notifications via email/SMS
- Dashboard KPIs and parcel history
- CSV export reports
- Role-based access for admin and staff
- Facilities/property profiles
- Recipient directory
- Parcel storage locations
- Couriers, delivery items, delivery methods, sellers
- To-do task tracking

## 3) Getting started
1. Create account and verify email/SMS  
2. Complete Account Setup (facility + contact + notifications)  
3. Add recipients and storage locations  
4. Start logging parcels and tracking status

## 4) Notifications
Email and SMS are supported. Enable in Account Setup or update later in settings.

## 5) Reports
Export parcel reports to CSV from the dashboard. Filter by status or date.

## 6) Plans and pricing
Basic, Standard, and Enterprise plans. Pricing is per user per month.

## 7) Integrations
API and webhook integrations are available. Share your system to confirm requirements.

## 8) Security
Role-based access and parcel status history logs. Use strong passwords and team access controls.

## 9) Profiles
- Facilities/Property: building details and contacts
- Recipients: types, contact, unit info, active status
- Couriers: company info, website, active status
- Parcel/Delivery Items: item types and categories
- Delivery Methods: pickup/delivery workflows
- Sellers: vendor list and contact info

## 10) Tasks (To-Do)
- Create tasks with due dates
- Add reminders and status

## 11) Parcel lifecycle
- Create parcel with recipient, status, location, tracking code
- Status values: pending, delivered, held, returned
- Scan updates status and records history

## 12) Account setup
- Facility details
- Facility usage
- Contact info
- Notification preferences
- Subscription plan
- Captcha verification

## 13) Admin tools
- Add users and set roles (admin/staff)
- View plan change history
- Review notification logs (email/SMS delivery)

## 14) Troubleshooting
- OTP not received: resend verification and check email/SMS settings
- Captcha failed: refresh and try again
- Empty lists: clear filters and confirm login
